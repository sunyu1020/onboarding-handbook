# 新人上手手册 Onboarding Handbook

> **从拿到 offer，到真正会干活。**

一个面向应届毕业生的 AI 工作上手工具：把「没人教你的隐性知识」变成看得见、用得上的真实工作地图。

## 为什么做这个

我是 2027 届应届生，秋招期间最深的感受是：**拿到 offer ≠ 会干活**。

学校教的是知识，不教「一个岗位具体怎么运转」——领导说的黑话听不懂、开会不知道记什么、周报憋两小时写不出三行、同事嘴里「很简单的事」做起来全是坑。这些隐性知识没人系统讲，全靠新人自己踩坑慢慢悟。

这个产品就是把「干过的人才知道的门道」显性化：AI 负责把零散信息整理成结构化的工作地图，你负责用它少踩坑。

## 产品架构（8 屏）

| # | 屏 | 核心能力 | AI 角色 |
|---|---|---|---|
| 1 | 开场页 | 产品定位 + 导航框架 | — |
| 2 | 今日工作台 | 粘贴排期 → AI 解析成结构化待办 → 回显可编辑 → 入库；手写月历 + 统计卡 + 动态时间线 | 解析排期文本 |
| 3 | 岗位拆解 ★ | **岗位名拆解**（输入岗位名 → 8 字段真实工作地图）+ **JD 拆解 Agent**（粘贴 JD / 上传截图 → 把「JD 写 XX」翻译成「实际是 XX」，支持追问对话） | DeepSeek 拆解 + 智谱 GLM-4V-Flash 截图提字 + 流式追问 |
| 4 | 项目台账 | 粘贴工作清单 → AI 整理成项目 → 进度阶段 / 逾期标红 / 风险预警；从待办一键导入 | 清单整理 |
| 5 | 会议纪要 | 文本 / docx / PDF / **录音** → AI 提炼结论 + 待办 + 待定问题 → 一键复制群发模板（带复选框和署名位）→ 待办同步工作台 | DeepSeek 提炼 + DashScope ASR 录音转写 |
| 6 | 周报与向上汇报 | **前端算数据快照，AI 只负责组织成文**：周报三段式 200-400 字 / 向上汇报 80-150 字，两种语气同一份事实 | 快照 → 成文 |
| 7 | 新人开挂室 | 书单（20 本，按优先级 + 阅读阶段 + 岗位筛选，藏书票封面）+ 新人困境（16 条，强硬/迂回/共赢三套解法） | —（纯本地，数据驱动） |
| 8 | 关于 & 初衷 | 创作初衷 + 小贴士 | — |

## 核心设计哲学

1. **AI 是核心引擎，但不是造假引擎**——「去掉 AI 也能完整用」的模块是设计失败；同时所有 AI 输出都**回显可编辑**，用户可以修正后再入库，AI 翻车不锁死用户。
2. **数据驱动生成，禁止 AI 编造**——第 6 屏周报是典型：待办/台账/纪要先由前端算出真实数据快照，AI 只拿快照组织成文，「快照里没有的细节不许编造」。
3. **内容配置化**——岗位库 29 个 / 困境库 16 条 / 书单 20 本全部是 JSON 数据，产品经理自己维护内容，代码只负责渲染。
4. **隐性知识显性化**——「JD 写『参与需求调研』→ 实际是『你拿着问题清单一坐两小时做访谈』」，这种只有干过的人才知道的细节，是这个产品的灵魂。

## 技术栈

- **前端**：Vite + 原生 JavaScript（无框架），单页滚动式 8 屏
- **持久化**：localStorage（`odb_` 前缀统一管理）
- **AI 服务**：
  - DeepSeek（deepseek-chat）：岗位拆解 / JD 拆解 / 纪要提炼 / 周报成文
  - 智谱 GLM-4V-Flash（免费）：JD 截图提字
  - 阿里云百炼 DashScope：会议录音实时转写（WebSocket 分片推流）
- **部署**：GitHub Pages（`/onboarding-handbook/` 路径）

## 本地运行

```bash
npm install
# 复制 .env.example 为 .env，填入三个 API Key
npm run dev
```

## AI 服务配置

`.env` 文件（已被 .gitignore 忽略，不会提交）：

```
VITE_DEEPSEEK_API_KEY=sk-xxxxx
VITE_ZHIPU_API_KEY=xxxxx
VITE_DASHSCOPE_API_KEY=sk-xxxxx
```

> ⚠️ `.env` 放真实 key（不上传）；`.env.example` 只放占位符（当模板上传）。
