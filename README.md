# 登陆岛 DengluDao

> **不漂流，来登陆。从拿到 offer，到真正会干活。**

一个面向应届毕业生的 AI 工作上手工具：把「没人教你的隐性知识」变成看得见、用得上的真实工作地图。

**线上体验**：https://sunyu1020.github.io/onboarding-handbook/

## 为什么做这个

我是 2027 届应届生，秋招期间最深的感受是：**拿到 offer ≠ 会干活**。

学校教的是知识，不教「一个岗位具体怎么运转」——领导说的黑话听不懂、开会不知道记什么、周报憋两小时写不出三行、同事嘴里「很简单的事」做起来全是坑。这些隐性知识没人系统讲，全靠新人自己踩坑慢慢悟。

这个产品就是把「干过的人才知道的门道」显性化：AI 负责把零散信息整理成结构化的工作地图，你负责用它少踩坑。

## 演示模式（无需 API Key）

考虑到面试官、体验者打开链接时不可能自己去配 Key，站点内置**演示模式**：检测不到 API Key 时自动进入，无需任何配置即可完整体验全部功能——

- 打开即自动播种一套完整示例数据（待办 / 项目台账 / 会议纪要 / 周报），各屏不是空壳
- 岗位拆解、JD 追问、纪要提炼、周报生成全部返回**预置的真实风格回答**（带流式打字机效果）
- 顶部有演示标识与「清空示例数据」出口，不污染你自己录入的数据
- 配置了 Key 则自动切换为真实 AI 调用，两套体验无缝共存

## 产品架构（8 屏）

| # | 屏 | 核心能力 | AI 角色 |
|---|---|---|---|
| 1 | 开场 Hero | 品牌标语 + 背景视频（桌面/移动端一致，四层兜底永不黑屏） | — |
| 2 | 今日工作台 | 粘贴排期 → AI 解析成结构化待办 → 回显可编辑 → 入库；手写月历 + 统计卡 + 动态时间线 | 解析排期文本 |
| 3 | 岗位拆解 ★ | **岗位名拆解**（输入岗位名 → 8 字段真实工作地图）+ **JD 拆解 Agent**（粘贴 JD / 上传截图 → 把「JD 写 XX」翻译成「实际是 XX」，支持追问对话）；29 岗扇形轮播岗位库，点击具体岗位后拆解 | DeepSeek 拆解 + 智谱 GLM-4V-Flash 截图提字 + 流式追问 |
| 4 | 项目台账 | 粘贴工作清单 → AI 整理成项目 → 进度阶段 / 逾期标红 / 风险预警；从待办一键导入 | 清单整理 |
| 5 | 会议纪要 | 文本 / docx / PDF / **录音** → AI 提炼结论 + 待办 + 待定问题 → 一键复制群发模板 → 待办同步工作台 | DeepSeek 提炼 + DashScope ASR 录音转写 |
| 6 | 周报与向上汇报 | **前端算数据快照，AI 只负责组织成文**：周报三段式 / 向上汇报 80-150 字，两种语气同一份事实；进入屏幕自动回填已存周报 | 快照 → 成文 |
| 7 | 新人开挂室 | 书单（20 本，按优先级 + 阅读阶段 + 岗位筛选，真实封面 + 悬浮详情 + 全屏阅读面板）+ 新人困境（16 条，强硬/迂回/共赢三套解法） | —（纯本地，数据驱动） |
| 8 | 关于 & 初衷 | 创作初衷 + 数据管理（导出/导入/清空） | — |

## 核心设计哲学

1. **AI 是核心引擎，但不是造假引擎**——「去掉 AI 也能完整用」的模块是设计失败；同时所有 AI 输出都**回显可编辑**，用户可以修正后再入库，AI 翻车不锁死用户。
2. **数据驱动生成，禁止 AI 编造**——第 6 屏周报是典型：待办/台账/纪要先由前端算出真实数据快照，AI 只拿快照组织成文，「快照里没有的细节不许编造」。
3. **内容配置化**——岗位库 29 个 / 困境库 16 条 / 书单 20 本全部是 JSON 数据，产品经理自己维护内容，代码只负责渲染。
4. **隐性知识显性化**——「JD 写『参与需求调研』→ 实际是『你拿着问题清单一坐两小时做访谈』」，这种只有干过的人才知道的细节，是这个产品的灵魂。
5. **零门槛体验**——无 Key 演示模式让任何打开链接的人（包括面试官）都能在 10 秒内看到产品完整价值。

## 技术栈

- **前端**：Vite + React 19 + TypeScript + Tailwind CSS 4（framer-motion、lucide-react）；混合架构——首屏 Hero 与全局浮窗导航为 React 组件，其余功能屏为原生 JS，渐进迁移中
- **视觉**：奶油毛玻璃 Cream Glassmorphism（深底 + 单一奶油强调色 #E1E0CC）
- **持久化**：localStorage（`odb_` 前缀统一管理，共 10 个 key，支持一键导出/导入）
- **AI 服务**：
  - DeepSeek（deepseek-chat）：岗位拆解 / JD 拆解 / 纪要提炼 / 周报成文
  - 智谱 GLM-4V-Flash（免费）：JD 截图提字
  - 阿里云百炼 DashScope：会议录音实时转写（WebSocket 分片推流）
- **部署**：GitHub Pages + GitHub Actions 自动部署（push main 即上线）

## 本地运行

```bash
npm install
npm run dev
# 无 .env 时自动进入演示模式，开箱即用
```

如需真实 AI 调用，复制 `.env.example` 为 `.env`，填入三个 API Key：

```
VITE_DEEPSEEK_API_KEY=sk-xxxxx
VITE_ZHIPU_API_KEY=xxxxx
VITE_DASHSCOPE_API_KEY=sk-xxxxx
```

> ⚠️ `.env` 放真实 key（不上传）；`.env.example` 只放占位符（当模板上传）。

## 部署

推到 `main` 分支后，GitHub Actions 自动构建并发布（build → upload-pages-artifact → deploy-pages）：

git push origin main
