## 本次任务：第 2 屏「今日工作台」

### 1. 按时段问候区（屏顶部）

- 按访问时段显示问候语：<12 点「早上好」/ 12-18 点「下午好」/ 其余「晚上好」，后接「，准备上道了」之类的短句
- 每个时段配 2~3 条新人场景文案随机展示一条，要具体、有共鸣，禁止鸡汤空话。参考基调：
  - 早上：「今天第一件事：打开待办，挑最难的先干」「昨天没回的消息，今天上午回掉」
  - 下午：「下午的会别只带耳朵去，带一个要问的问题」「午休回来先看一眼今天还剩几件事」
  - 晚上：「下班前花 3 分钟勾掉做完的事，明天的你会感谢现在的你」「今天没干完的，判断一下：是真干不完，还是不敢开始」

### 2. 粘贴排期 → AI 解析（本屏的 AI 核心）

- 输入框 +「解析」按钮，textarea 支持粘贴任意纯文本工作排期/待办/聊天记录里领到的活
- 点击解析 → 调用 DeepSeek API，把乱糟糟的文本整理为结构化待办列表
- **解析 Prompt 新建文件 `src/prompt-todo-parse.txt`**，用 `?raw` 方式逐字导入（与第 3 屏 prompt.txt 同样机制，禁止在 JS 里内联 Prompt 字符串）。Prompt 内容如下（可微调措辞，不可改变要求）：

```
你是一个职场待办整理助手。用户会粘贴一段杂乱的工作文本（可能是排期、待办清单、会议里领到的任务、聊天记录等），请把它们整理为结构化的待办列表。

要求：
1. 只提取明确的"要做的事"，寒暄、讨论、已确认完成的内容不要提取
2. 每条提取：事项名（动宾结构，具体到动作）、截止日期（文本里有就提取为 YYYY-MM-DD，没有就填 null）、优先级（高/中/低：有明确 deadline 且临近=高，有 deadline 但还远=中，没提=低）、备注（补充信息，没有填 null）
3. 日期解析规则：今天是 {{TODAY}}。"周五""下周一"等相对表述要换算成具体日期，换算不了就填 null
4. 事项名里保留关键上下文（谁派的活、哪个项目），但不超过 30 字
5. 如果文本里确实没有任何可执行事项，返回空数组，并在 note 字段说明原因

只输出 JSON，不要任何其他文字，格式：
{
  "todos": [
    {"title": "事项名", "dueDate": "YYYY-MM-DD 或 null", "priority": "高/中/低", "note": "备注或 null"}
  ]
}
```

- 调用时把 `{{TODAY}}` 替换为当天日期（`new Date()` 本地化格式化，注意月份从 0 开始的坑）
- **解析结果先回显、可编辑、再入库**：展示为待确认列表，每条可改标题/日期/优先级、可删除单条，用户点「确认添加」后才写入 localStorage。禁止解析完直接静默入库
- 提供「试一试」按钮：点击自动填入一段示例排期文本（自己写 5~6 条真实感的杂乱待办，如"周三前把竞品分析给王总""下周一例会要汇报进度 还得做ppt""回复采购部邮件"），方便演示
- 异常兜底复用第 3 屏的模式：无 key 提示 / 加载中 / HTTP 错误码（401/402/429）/ JSON 解析失败，都要有明确提示，不能白屏

### 3. 四大统计卡片

数据来源：localStorage 中的待办（数据结构见下文）。四卡片一行网格（移动端 2×2）：

1. **进行中**：未完成待办总数 + 副文本周新增数
2. **待办**：未完成数 + 副文本日到期数
3. **延期风险**：`dueDate < 今天` 且未完成的数量；数字 >0 时卡片标红；点击平滑滚动到 `#screen-4`（台账屏现在是占位，跳过去即可，不报错）
4. **本周完成度**：环形进度（分母=本周一以来创建的待办总数，分子=其中已完成的）。**手写 SVG 圆环**（stroke-dasharray 实现），禁止引入图表库。分母为 0 时显示「—」

### 4. 待办列表区

- 解析入库的待办逐条展示：勾选框（完成/撤销）、优先级色点（高=红 中=橙 低=蓝）、标题、截止日期（逾期且未完成标红显示「已逾期 X 天」）、删除按钮
- 已完成的事项置灰划线，可撤销
- 空状态：引导文案 + 指向粘贴输入框
- 顶部小 tab：「全部 / 未完成 / 已完成」三个筛选

### 5. 本月日历视图

- **纯 JS 手写月历**（7 列网格，周一为一周起点），禁止装日历库
- 有待办到期的日期：格子里加小圆点（高优先级红点，其他灰点）
- 今天：呼吸动画边框（@keyframes 缩放 box-shadow，与整体风格一致的克制动画）
- 点击有待办的日期：下方浮出当日待办简要列表（有几条、哪些未完成），点空白处收起。不做更多交互
- 上/下月切换按钮，默认当前月

### 6. 最近动态时间线

- 倒序展示最新 6 条动态，每条含：图标（emoji 即可）、事件名、相对时间（如「5 分钟前」「昨天 14:30」）
- 动态类型 v1 至少支持：新增待办（含条数）、完成待办、收藏岗位
- 数据存 localStorage，结构：`{type, title, time}` 数组，超 50 条截断旧数据
- **对第 3 屏的唯一允许改动**：在"收藏岗位成功"的代码位置加一行记录动态的调用（如 `logActivity('job-save', '收藏岗位：XX')`），除此之外第 3 屏任何逻辑一行不改
