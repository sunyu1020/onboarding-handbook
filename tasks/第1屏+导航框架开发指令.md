## 设计细节

### 配色

现有 3 套配色预览（blue / orange / green），先全部保留。我会在看完整体框架后选定一套，届时删除其余两套和切换器。

所有颜色用 CSS 变量（`--bg`、`--text`、`--primary` 等），已经定义在 style.css 里了，直接用。

### 第 1 屏布局

```
┌─────────────────────────────┐
│                             │
│                             │
│      新人上手手册            │
│   从拿到 offer，到真正会干活  │
│                             │
│    [ 打开我的工作台 ]        │
│                             │
│             ↓               │
│                             │
└─────────────────────────────┘
```

- 大标题用大字号（clamp(2rem, 5vw, 3.5rem)），font-weight 700-800
- slogan 用中字号，颜色比标题淡一级
- CTA 按钮用 --primary 背景色，白色文字，圆角，hover 有轻微上浮 + 阴影
- 向下箭头在屏幕底部居中，做 CSS bounce 动画

### 顶部导航

```
┌──────────────────────────────────────────┐
│  工作台  岗位拆解  台账  汇报  成长      │
└──────────────────────────────────────────┘
```

- 固定在顶部（position: fixed / sticky）
- 半透明背景 + backdrop-filter: blur(12px)
- 向下滚动时 translateY(-100%) 隐藏，向上滚动时 translateY(0) 显现
- 当前屏的高亮（用 IntersectionObserver 监测哪个 section 在视口中，对应导航项加 active 样式）——**这个可以做，但如果太复杂就先不做，后面补**
