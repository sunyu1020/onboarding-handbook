## 本任务范围（只做这些）

做一个单页 `index.html`，**只包含第 3 屏岗位拆解**。其他 7 屏后续任务再做，导航栏先不做。

### 页面布局（自上而下）

1. **标题区**：「岗位拆解」大标题 + 副标题「输入岗位名，AI 给你一份真实工作地图」
2. **输入区**：
   - 文本输入框，placeholder「输入你的岗位，如：新媒体运营 / 产品经理 / 审计」
   - 输入框为空或聚焦时，下方展开**预置岗位快速选择**：读取 jobs.json 的 29 个岗位，按 category 分组显示岗位名，支持关键字过滤，点击即填入输入框
3. **生成按钮**：「拆解这个岗位」
4. **结果区**：8 个模块卡片（见下）
5. **底部「我的岗位库」**：已收藏的岗位列表（localStorage），点击展开回看完整 8 模块，支持删除

### AI 生成链路（核心）

- System Prompt：**一字不改**地使用 `prompt-岗位拆解.md` 中的定稿 Prompt（含 few-shot 范例与铁律，禁止自行删改）
- 调用方式：`fetch` POST `https://api.deepseek.com/chat/completions`
  - `model: "deepseek-chat"`
  - `messages`: [{role:"system", content: 定稿Prompt}, {role:"user", content: 岗位名 + "宁可写满也不要提前收工"}]
  - `temperature: 0.7`，`max_tokens: 2000`
  - `response_format: { type: "json_object" }`
- 返回的 JSON 直接就是 8 字段结构，解析后渲染

### 8 个结果模块（字段名与 JSON 严格一致，按此顺序渲染）

| # | 字段 | 展示形式 |
|---|---|---|
| 1 | oneLineTruth 岗位本质 | 大字突出，独立样式 |
| 2 | dailyWork 日常在干什么 | 列表 |
| 3 | kpi 考核怎么算 | 列表 |
| 4 | keyCompetencies 关键能力 | 3~4 个标签卡片 |
| 5 | firstMonthPitfalls 第一个月的坑 | 列表 |
| 6 | collaboration 打交道地图 | 列表，每条"角色：说明" |
| 7 | week1Checklist 第一周清单 | 复选框样式（纯展示，点击可勾选但不持久化） |
| 8 | interviewSecrets 面试内行话 | 列表 |

- 结果卡片右上角放「收藏到岗位库」按钮
- 收藏时生成的数据结构与 jobs.json 对齐：`id` 用时间戳，`verifiedBy` 写「AI 生成（你自己拆解）」，`name` 为用户输入的岗位名

### 数据与存储

- localStorage key：`job_library`，存数组
- 预置 29 岗直接从 jobs.json 读取展示，与用户生成的分开（预置的展示完整字段，不需要收藏按钮）

### 状态处理（必须做全，缺一不可）

1. **未配置 key**（`import.meta.env.VITE_DEEPSEEK_API_KEY` 为空）：点生成按钮后显示引导卡片「还没配置 DeepSeek API Key：复制 .env.example 为 .env，填入你的 key 后刷新页面」；预置 29 岗浏览不受影响
2. **加载中**：按钮进入 loading 态，结果区显示占位动画 + 文案「正在拆解，约需 10~20 秒…」
3. **API 报错**：用人话翻译错误（401→key 无效；402→额度不足；429→请求太频繁；其他→网络异常），显示错误卡片 + 重试按钮，禁止白屏
4. **JSON 解析失败**：尝试从返回文本中截取第一个 `{` 到最后一个 `}` 重试一次，仍失败按报错处理
