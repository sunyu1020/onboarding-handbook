## 一、任务背景(为什么升级)

现有第 7 屏书单的封面是 **CSS 藏书票**(div 里放书名+作者文字),点击卡片打开的是**右侧抽屉**,里面只有推荐理由和「在线搜索」按钮(跳豆瓣搜索页)。

本次按用户新需求升级为:

1. **封面显示书的真实封面图**(不再用纯文字藏书票)
2. **点击封面直接"打开电子书阅读"** —— 但**不托管、不盗版任何全文**,而是打开**页内全屏阅读面板**:展示这本书的精华内容(内容概述 + 读者评价 + 正版阅读入口),带翻页动效,**完全不离开页面**
3. **鼠标选中(悬停/点选)卡片时呈放大选中态**
4. **选中后在书单区右侧展示详情面板**:书名、作者、相关标签、内容概括,下面是**真实的网络用户评价**(来自豆瓣短评,数据已抓取好,直接渲染)

> 版权红线:严禁在页面内嵌入或跳转任何盗版全文链接。正文阅读走「微信读书」正版渠道外链(新标签打开),这是唯一允许的外部阅读入口。

## 二、数据源(已就绪,books.json 已升级到 v2.1,只读使用,严禁再改)

**`data/books.json`** 每本书新增了 5 个字段(旧字段 id/title/author/category/priority/reason/forRoles/status/readingStage 一个没动):

```json
{
  "id": "b01",
  "title": "金字塔原理",
  "author": "芭芭拉·明托",
  "category": "逻辑表达",
  "priority": "P0",
  "reason": "汇报和写文档的底层结构，'结论先行'四个字够你用十年",
  "forRoles": ["全部"],
  "status": "want",
  "readingStage": "入职前",
  "coverUrl": "https://img9.doubanio.com/view/subject/s/public/s32276605.jpg",
  "doubanId": "33391219",
  "doubanUrl": "https://book.douban.com/subject/33391219/",
  "summary": "麦肯锡首位女咨询顾问芭芭拉·明托的经典方法论：结论先行、以上统下、归类分组、逻辑递进……",
  "reviews": [
    { "user": "我是老林", "text": "金字塔的基本原则是：结论先行、以上统下、分组归类、逻辑递进。……" },
    { "user": "巧克力趣多多", "text": "很干。干巴巴" }
  ]
}
```

字段说明:
- `coverUrl`:豆瓣/百科 CDN 的真实封面图外链(其中 b20 杜拉拉用的是百度百科 `bkimg.cdn.bcebos.com` 直链)
- `doubanUrl`:豆瓣条目页(阅读面板里「查看豆瓣详情」按钮跳这个,比旧版搜书名更精准)
- `summary`:内容概述(约 50-100 字,直接渲染)
- `reviews`:豆瓣真实短评,`user` 是评论者昵称(个别丢失的记为「豆瓣用户」),`text` 是原文,数量 1-3 条不等(**前端按实际数量渲染,不许补编**)

import 方式照旧:
```js
import booksData from '../data/books.json'
```

## 三、实现细节

### 3.1 真实封面图 + 降级

- 卡片封面区域结构改为:`open-book-cover` 容器内放一个 `<img>`(src=`coverUrl`,alt=`title`)+ **保留原有的藏书票文字层**
- 图片加载成功:img 显示,文字层隐藏
- 图片加载失败(`onerror`,海外网络可能连不上 doubanio.com CDN):**img 隐藏,文字层(藏书票)显示** —— 保证任何网络环境下卡片都不破相
- 实现建议:img 默认 `display:none`,监听 `onload` 后显示并隐藏文字层;`onerror` 直接移除 img 或保持隐藏。不要用 CSS 背景图做封面(无法可靠捕获失败)
- 封面图 `object-fit: cover` 填满卡片,圆角与卡片一致

### 3.2 选中放大态

- `.open-book-card` 加过渡:`transition: transform .2s ease, box-shadow .2s ease`
- **悬停**(`:hover`):`transform: scale(1.04)` + 阴影加深
- **选中**(当前右侧详情面板正在展示的书,维护一个 `selectedBookId` 变量):`transform: scale(1.06)` + 主题色描边/高亮阴影,与 hover 区分
- 卡片内其他元素(圆点、角签)跟随缩放即可,无需特殊处理

### 3.3 右侧详情面板(桌面端)

- 在书单区域右侧新增固定面板 `.open-detail-panel`(桌面端 `>1024px` 显示;≤1024px 隐藏,此时点卡片直接进阅读面板)
- 默认空态:占位文案(如「悬停或点击一本书,这里会展示它的详情」),弱化显示
- 选中卡片(点击卡片任意处)后更新面板内容:
  - 封面小图(带同样 onerror 降级,可复用)
  - **书名**(大)、**作者**
  - **标签行**:category / priority 徽标 / forRoles / readingStage(复用现有抽屉的标签样式)
  - **内容概括**:`summary` 原文渲染
  - **真实用户评价**:标题「读者评价 · 来自豆瓣」,下面逐条渲染 `reviews[]`:昵称(`user`)+ 评价原文(`text`),每条约 2 行,来源小字标注「豆瓣短评」
  - 面板底部两个按钮:「页内阅读」(打开 3.4 的全屏阅读面板)和「豆瓣详情」(`window.open(doubanUrl)`)
- 点选另一本书时面板内容平滑切换(可加简单 fade,不加动画库)

### 3.4 点击卡片 → 全屏阅读面板(核心)

替换现有 `openBookDrawer(b)` 右侧抽屉逻辑(抽屉保留或移除均可,但**阅读面板必须全屏/近全屏遮罩层**):

- 点击卡片(圆点除外)→ 打开全屏遮罩 `.open-reader`
- 结构:顶部标题栏(书名 + 关闭 ×)→ 中间内容区(分页)→ 底部操作栏
- **分页内容(3 页,左右翻页动效)**:
  1. **这本书讲什么**:`summary` 全文 + 一句话推荐理由 `reason`
  2. **读者怎么说**:`reviews` 逐条(昵称 + 原文),顶部小字「以下短评来自豆瓣,按热度排序」
  3. **开始阅读**:一段简短说明(如「这是正版阅读入口,第一次使用会跳转微信读书」)+ 大按钮「去微信读书读全文」(新标签,`https://weread.qq.com/web/search/books?keyword=${encodeURIComponent(title)}`)+ 次按钮「查看豆瓣条目」(新标签,`doubanUrl`)
- 翻页动效:底部「上一页 / 下一页」按钮 + 键盘左右方向键;切换时内容区做横向滑入/滑出过渡(translateX + opacity,纯 CSS transition)
- 关闭:点遮罩、点 ×、按 Esc;关闭后恢复原页面滚动位置(打开时锁定 body 滚动,关闭时解锁)
- **注意**:若微信读书搜索链接格式实测打不开,退化为 `https://weread.qq.com/` 首页,并在验收清单里说明

### 3.5 保留不动的旧逻辑

- 阅读状态圆点 `cycleBookStatus()` 及 localStorage `odb_book_status` **原样保留**(圆点点击事件与卡片点击事件互不干扰)
- 岗位 + 阶段 AND 筛选 `renderRoleFilter()` / `renderStageFilter` **原样保留**
- 排序逻辑(P0 → P1 → P2 → 阶段 → 标题)**原样保留**

## 四、防坑清单(必须逐条落实)

1. **封面必须带 onerror 降级**:豆瓣图床在国内正常、部分海外网络慢/不通,降级到藏书票后页面必须依然完整美观(这是验收重点,模拟断网截图验证)
2. **严禁编造数据**:`reviews` 数量 1-3 条不等,`user` 可能是「豆瓣用户」,`summary` 只渲染不改写;不要"补"第 4 条评价、不要润色评价文字
3. **版权红线**:不嵌入任何全文、不跳转盗版链接;正文阅读只有微信读书外链一条路
4. 阅读状态只写 `odb_book_status`,不碰 books.json(**books.json 本次已升级为 v2.1,只读**)
5. 不装任何新依赖;翻页动效、放大态、右侧面板全部 CSS/原生 JS
6. 深浅色模式:新加的封面图容器、右侧面板、全屏阅读器全部适配 `prefers-color-scheme`(与现有做法一致,深色下无死黑死白;评价文字用次级色保证可读)
7. 移动端适配:
   - ≤1024px:右侧详情面板隐藏,点卡片直接开阅读面板
   - ≤768px:书单 1-2 列不变;阅读面板全屏铺满,翻页按钮触控区 ≥ 40px
   - 阅读面板打开时 body 不滚动(overflow hidden),关闭恢复
8. 键盘/无障碍:阅读面板支持 Esc 关闭、左右键翻页;卡片和按钮加 `cursor: pointer`
9. 只改第 7 屏书单子模块:困境 tab、第 1-6 屏、prompt*.txt 一律不碰(git diff 里不应出现)
