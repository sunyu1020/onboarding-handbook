## 任务一:配色预览「隐藏」而非删除

**背景**:导航右侧的 `#theme-preview`(配色预览,3 个色点)是临时控件,正常访问者(尤其面试官)不应看到;但样式阶段还没开始,后面选配色还需要它。

**做法**:
1. `index.html` 的 `<div class="theme-preview" id="theme-preview">` 加 `hidden` 属性
2. `src/main.js` 主题初始化逻辑处增加:当 URL 带查询参数 `?theme=1` 时移除该 `hidden`(即 `location.search.includes('theme=1')` → `document.getElementById('theme-preview').removeAttribute('hidden')`)
3. `main.js` 484 行附近的 localStorage key 清单注释处补一行:`theme_preview  配色预览开关(临时,?theme=1 唤出,定稿配色后整体删除)`

**防坑**:
- 不要删 THEME_KEY 读取逻辑,默认主题仍读 localStorage、无则 `'blue'`
- style.css 里 `.theme-preview` 相关样式不删(隐藏期间无害)

## 任务三:数据导出 / 导入 / 清空(放第 8 屏)

**背景**:用户数据全存 localStorage,清缓存/换电脑即全丢。加数据管理能力。

**位置**:第 8 屏(`#screen-8`)`.about-end` 之后,新增一个「数据管理」小区块(小标题 + 三个按钮,朴素排版即可):`导出我的数据` / `导入数据` / `清空全部数据`,外加一个隐藏的 `<input type="file" id="data-import-file" accept=".json" hidden>` 和一行提示文本区。

**涉及 localStorage key 全集(共 10 个,导出/导入/清空都要覆盖)**:

| key | 内容 |
|---|---|
| `odb_todos` | 待办 |
| `odb_activities` | 最近动态 |
| `odb_projects` | 项目台账 |
| `odb_meetings` | 会议纪要 |
| `odb_reports` | 周报 |
| `odb_book_status` | 书单阅读状态 |
| `odb_dilemma_fav` | 困境收藏 |
| `job_library` | AI 生成岗位收藏 |
| `preset_favorites` | 预置岗位收藏(id) |
| `theme_preview` | 主题选择 |

**导出**:
- 读取上述 key(不存在的跳过),组装:
```json
{ "app": "onboarding-handbook", "version": 1, "exportedAt": "ISO时间", "data": { "odb_todos": [...], ... } }
```
- 用 Blob + `URL.createObjectURL` 触发下载,文件名 `onboarding-backup-YYYY-MM-DD.json`
- 完成后提示区显示「已导出,N 项数据已保存到文件」

**导入**:
- 选文件后 `JSON.parse`,校验:必须有 `app === 'onboarding-handbook'` 且 `data` 为对象,不合法提示「文件格式不对」
- 合法后弹 `confirm`,摘要列出将导入的内容(如「待办 12 条 / 项目 3 条 / 书单状态 5 条…」,按各 key 数组长度或对象键数统计)
- **导入前先自动下载一份当前数据的备份**(直接复用导出函数,防手滑覆盖)
- 确认后逐 key `localStorage.setItem`(只覆盖文件里出现的 key,不删文件里没有的 key),然后 `location.reload()`

**清空**:
- 两次 `confirm`(第二次文案明确「不可恢复」)→ 移除全部 10 个 key → `location.reload()`

**防坑**:
- 各屏刷新统一用 `location.reload()`,**不要**手动逐屏调渲染函数(8 屏容易漏)
- 导出的 JSON 里 `data` 各 key 的值保持原始结构,不做任何字段转换

## 任务四:空态统一组件

**背景**:各屏空态目前是零散纯文字,先统一成组件,样式阶段一处美化全局生效。

**做法**:
1. `main.js` 通用工具区加:
```js
function emptyStateHTML(icon, title, hint = '') {
  return `<div class="empty-state">
    <span class="empty-state-icon" aria-hidden="true">${icon}</span>
    <p class="empty-state-title">${title}</p>
    ${hint ? `<p class="empty-state-hint">${hint}</p>` : ''}
  </div>`;
}
```
2. 替换以下 8 处空态为该组件(icon 用 emoji,文案沿用现有或微调,可带一句引导 hint):

| 位置 | id | 建议文案(title / hint) |
|---|---|---|
| 第2屏 待办清单 | `dash-todo-empty` | 还没有待办 / 粘贴上面的排期,点「解析」试试 |
| 第2屏 最近动态 | `dash-act-empty` | 暂无动态 / 完成第一条待办后,这里会开始记录 |
| 第3屏 岗位收藏 | `fav-empty` | 还没有收藏的岗位 / 点岗位库格子上的 ☆ 试试 |
| 第4屏 项目列表 | `proj-empty` | 台账还是空的 / 粘贴工作清单,点「整理」生成台账 |
| 第5屏 最近纪要 | `meet-history-empty` | 还没有提炼过的纪要 / 粘贴一段会议记录试试 |
| 第6屏 历史周报 | `rep-history-empty` | 暂无历史周报 / 点「生成本周周报」试试 |
| 第7屏 书单筛选 | `open-books-empty` | 这个组合暂时没有推荐 / 放宽筛选看看 |
| 第7屏 右侧详情 | `open-detail-empty` | 悬停或点击一本书 / 这里会展示它的详情 |

3. `style.css` 加最小样式:`.empty-state` 居中 + 内边距,`.empty-state-icon` 字号放大一档,`.empty-state-title` 常规灰字,`.empty-state-hint` 更浅灰小字。**仅此而已,不做美化。**

**防坑**:
- 只换文案的渲染方式,**不改各空态的显隐逻辑**(`hidden` 切换、条件判断保持原样)
- `dash-todo-empty` 是 JS 动态填充的,替换的是填充的 HTML 字符串
