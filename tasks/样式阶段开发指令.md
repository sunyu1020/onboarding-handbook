## 设计基调(先读这一段再动手)

这是一个**求职作品集**里的产品:「新人上手手册」——面向应届生的效率工具。视觉目标:**专业、克制、有呼吸感**,像 Linear/飞书一类的现代工具,不要花哨营销页。

六条硬原则:

1. **颜色只用 CSS 变量**(`--bg/--surface/--surface-2/--border/--text/--text-2/--accent/--accent-strong/--accent-soft/--danger/--danger-soft/--shadow-sm/--shadow-md`),任何地方禁止出现硬编码色值。三套主题 + 深色模式必须同时成立——改完用 `?theme=1` 逐套检查。
2. **系统字体栈不动**,不引入外部字体(加载慢、部署环境不可控)。
3. **圆角/阴影/间距成体系**,不逐个拍脑袋(见任务一 tokens)。
4. **动效克制**:过渡 0.2~0.3s ease,只做 hover/展开/弹层类微交互;所有动画包在 `@media (prefers-reduced-motion: reduce)` 里降级为无动画。
5. **HTML 允许加装饰性元素**(wrapper div、装饰 span、图标),但**禁止改任何 id、data-* 属性和 JS 依赖的 class 名**。
6. **JS 一行不改**。唯一例外:若某处必须动 DOM 才能实现布局,先停下来在完成汇报里说明,不要自行改。

## 任务一:设计 tokens 定稿

在 `:root`/`[data-theme]` 变量区之后新增全局 tokens(只定义一次,后续全部引用):

```css
:root {
  --radius-sm: 8px;
  --radius-md: 12px;
  --radius-lg: 16px;
  --shadow-lg: 0 12px 32px rgba(27, 36, 52, 0.14); /* 深色模式需在媒体查询里给深色版本 */
  --space-1: 4px; --space-2: 8px; --space-3: 12px;
  --space-4: 16px; --space-5: 24px; --space-6: 32px; --space-7: 48px;
  --ease: cubic-bezier(0.25, 0.8, 0.5, 1);
}
```

然后**全站对齐**:

- 圆角:卡片 `--radius-md`,弹层/阅读器 `--radius-lg`,小按钮/输入框/标签 `--radius-sm`。把现有各处散落的 4px/6px/10px/14px/18px 统一收敛到三档。
- 间距:各屏 section 之间统一 `--space-7` 上下;卡片内边距统一(现在 dash-card/proj-card/meet-card/rep-panel 各写各的,抽成一致的 padding)。
- 字号梯度收敛为 5 档:正文 14 / 辅助 13 / 小字 12 / 卡片标题 16 / 区块标题 20~22(各屏 header 的 h2 统一为同一字号字重,section-sub 统一为 text-2 色)。
